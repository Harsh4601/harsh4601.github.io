# Company Logos

This directory contains company logos for the professional experience section.

## Required Logo Files

Add the following logo files to this directory:

- `amazon.png` - Amazon logo
- `enphase.png` - Enphase Energy logo  
- `hectra.png` - Hectra Services logo

## Logo Specifications

- **Format**: PNG (with transparency preferred)
- **Size**: Recommended 120x120px or larger (will be scaled to 60x60px)
- **Aspect Ratio**: Square (1:1) works best
- **Background**: Transparent or white background

## Fallback Behavior

If logo files are not found, the website will automatically display styled placeholder initials:
- Amazon: Orange "A"
- Enphase Energy: Blue "E"
- Hectra Services: "HS"

## Where to Get Logos

You can download company logos from:
- Company official websites (press/media kits)
- [Simple Icons](https://simpleicons.org/) - Open source brand icons
- [Logo.dev](https://logo.dev/) - Brand logo API
- Company brand guidelines pages

Make sure you have permission to use the logos and comply with any brand guidelines.
