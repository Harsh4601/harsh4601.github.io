# Harsh Londhekar - Portfolio Website

A sleek, modern portfolio website with Apple-inspired dark theme design and smooth animations.

## Features

- Modern dark theme design inspired by Apple's aesthetic
- Smooth scroll and animations
- Responsive layout for all devices
- Interactive UI elements with hover effects
- Contact form
- Timeline-based experience and education sections
- Project showcase
- Skills categorization

## Technologies Used

- HTML5
- CSS3 (with modern features like CSS Grid, Flexbox, and CSS Variables)
- JavaScript (ES6+)
- Intersection Observer API for scroll animations
- Font Awesome for icons

## Setup and Usage

1. Clone the repository
2. Open the `index.html` file in your web browser
3. To make edits:
   - Modify `index.html` for content changes
   - Edit `styles/main.css` for styling changes
   - Update `scripts/main.js` for behavior and animations
